Política de Privacidade

Aplicativo RADAR do Choque Sinaptico. Última atualização: 9 de novembro de 2026.

1. Quem é o responsável

O RADAR do Choque Sinaptico pertence ao dono do canal Choque Sinaptico no YouTube, que é também o único usuário do aplicativo. Ele roda no computador do dono do canal e serve para acompanhar os números do próprio canal e sugerir os temas dos próximos vídeos. O aplicativo usa os Serviços de API do YouTube.

2. Quais dados o aplicativo acessa

Com a autorização do dono do canal, feita na tela de permissão do Google, o aplicativo lê apenas os relatórios do YouTube Analytics do canal do próprio dono, com a permissão somente de leitura yt-analytics.readonly. São números agregados do canal e de cada vídeo, como visualizações, tempo assistido, inscritos e de onde vieram as visualizações.

O aplicativo não publica, não edita e não apaga nada no YouTube. Não acessa dados de espectadores, inscritos ou visitantes como pessoas, nem de qualquer outra conta. Não coleta nome, e-mail, localização, contatos ou dados de pagamento de ninguém.

Este site não usa cookies, formulários, scripts nem ferramentas de rastreamento. Ele é hospedado pelo GitHub Pages, que registra o endereço IP de quem visita por motivo de segurança, conforme a Declaração de Privacidade do GitHub.

3. Como os dados são usados

Os dados são usados só para mostrar ao dono, numa tela local no computador dele, como o canal está indo e quais vídeos funcionaram melhor, e para ajudar a escolher o tema do próximo vídeo.

Os dados não são usados para publicidade, para criar perfis de pessoas nem para treinar modelos de inteligência artificial.

4. Com quem os dados são compartilhados

Com ninguém. Os números do YouTube Analytics ficam no computador do dono. O aplicativo pode mandar ao próprio dono, por um bot privado do Telegram, avisos de funcionamento (por exemplo, que uma coleta falhou), sem números do YouTube Analytics. Essas mensagens passam pelos servidores do Telegram, conforme a Política de Privacidade do Telegram.

Nenhum dado é vendido, alugado, compartilhado ou transferido a terceiros.

5. Como os dados são guardados e protegidos

A autorização do Google é um token de atualização guardado cifrado, com a proteção de dados do próprio Windows, numa pasta da conta de usuário do computador do dono, separada do código do aplicativo e fora de qualquer repositório. Esse token não é enviado a servidores de terceiros. Toda comunicação com o Google é feita por conexão criptografada (HTTPS).

6. Por quanto tempo os dados ficam guardados e como apagá-los

Os números lidos do YouTube Analytics são renovados a cada coleta e deixam de ser exibidos e guardados depois de, no máximo, 30 dias. O token fica guardado até que o dono revogue a autorização ou apague o arquivo. A autorização pode ser revogada a qualquer momento na página de permissões da Conta do Google; depois disso, o aplicativo perde o acesso imediatamente.

7. Uso Limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Termos do YouTube e do Google

Ao usar este aplicativo, você concorda em ficar vinculado aos Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

9. Alterações nesta política

Se o uso de dados do aplicativo mudar, esta página será atualizada antes da mudança, com a nova data no topo.

10. Contato

Dúvidas sobre esta política podem ser enviadas ao e-mail de suporte exibido na tela de permissão do Google ou pelo canal no YouTube.
