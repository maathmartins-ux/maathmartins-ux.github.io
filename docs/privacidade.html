Política de Privacidade

Aplicativo Choque Sinaptico. Última atualização: 27 de setembro de 2026.

1. Quem é o responsável

O aplicativo Choque Sinaptico pertence ao dono do canal Choque Sinaptico no YouTube, que é também o único usuário do aplicativo. Ele roda no computador do dono do canal e serve para publicar e organizar os vídeos desse canal. O aplicativo usa os Serviços de API do YouTube.

2. Quais dados o aplicativo coleta

Com a autorização do dono do canal, feita na tela de permissão do Google, o aplicativo acessa apenas a conta do YouTube do próprio dono, por meio da API de Dados do YouTube. Os dados acessados são:

  • Dados do canal: identificador, nome e informações básicas do canal do dono.
  • Vídeos do canal: os arquivos de vídeo enviados pelo dono, com título, descrição, tags, idioma, categoria, status de privacidade, data de publicação e status de processamento.
  • Miniaturas e legendas dos vídeos do canal.
  • Playlists do canal e os vídeos que elas contêm.

O aplicativo não coleta dados de espectadores, inscritos, visitantes ou de qualquer outra conta. Não coleta nome, e-mail, localização, contatos ou dados de pagamento de ninguém.

Este site não usa cookies, formulários, scripts nem ferramentas de rastreamento. Ele é hospedado pelo GitHub Pages, que registra o endereço IP de quem visita por motivo de segurança, conforme a Declaração de Privacidade do GitHub.

3. Como os dados são usados

Os dados são usados só para as tarefas de publicação do próprio canal: enviar e agendar vídeos; preencher e corrigir título, descrição e tags; definir miniaturas; enviar legendas; criar playlists e colocar vídeos nelas; conferir o status de processamento dos vídeos; e avisar o dono do canal quando um vídeo é publicado.

Os dados não são usados para publicidade, para criar perfis de pessoas nem para treinar modelos de inteligência artificial.

4. Com quem os dados são compartilhados

  • YouTube: os vídeos e as informações de cada vídeo são enviados ao YouTube, que é o destino da publicação.
  • Telegram: depois de cada publicação, o link público do vídeo no YouTube é enviado a um bot privado do Telegram, que avisa apenas o próprio dono do canal. A mensagem passa pelos servidores do Telegram, conforme a Política de Privacidade do Telegram.

Fora isso, nenhum dado é vendido, alugado, compartilhado ou transferido a terceiros.

5. Como os dados são guardados e protegidos

A autorização do Google é um token de atualização guardado num arquivo dentro da pasta da conta de usuário do computador do dono, separado do código do aplicativo e fora de qualquer repositório. Esse token não é enviado a servidores de terceiros. Toda comunicação com o Google é feita por conexão criptografada (HTTPS). Os identificadores e os links dos vídeos publicados ficam em registros locais do aplicativo, no mesmo computador. Os vídeos em si ficam no YouTube.

6. Por quanto tempo os dados ficam guardados e como apagá-los

O token fica guardado até que o dono do canal revogue a autorização ou apague o arquivo do token. A autorização pode ser revogada a qualquer momento na página de permissões da Conta do Google; depois disso, o aplicativo perde o acesso ao canal imediatamente e o arquivo do token deixa de ter uso. Os registros locais com identificadores e links de vídeos podem ser apagados pelo dono a qualquer momento.

7. Uso Limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Termos do YouTube e do Google

Ao usar este aplicativo, você concorda em ficar vinculado aos Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

9. Alterações nesta política

Se o uso de dados do aplicativo mudar, esta página será atualizada antes da mudança, com a nova data no topo.

10. Contato

Dúvidas sobre esta política podem ser enviadas ao e-mail de suporte exibido na tela de permissão do Google ou pelo canal no YouTube.
