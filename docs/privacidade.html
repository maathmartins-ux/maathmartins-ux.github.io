Política de Privacidade

Aplicativo Choque Sinaptico. Última atualização: 27 de setembro de 2026.

1. Quem é o responsável

O aplicativo Choque Sinaptico pertence ao dono do canal Choque Sinaptico no YouTube, que é também o único usuário do aplicativo. Ele roda no computador do dono do canal e serve para publicar e organizar os vídeos desse canal. O aplicativo usa os Serviços de API do YouTube.

2. Quais dados o aplicativo coleta

Com a autorização do dono do canal, feita na tela de permissão do Google, o aplicativo acessa apenas a conta do YouTube do próprio dono, por meio da API de Dados do YouTube. Os dados acessados são:

  • Dados do canal: identificador, nome e informações básicas do canal do dono.
  • Vídeos do canal: os arquivos de vídeo enviados pelo dono, com título, descrição, tags, idioma, categoria, status de privacidade e data de publicação.
  • Miniaturas e legendas dos vídeos do canal.
  • Playlists do canal e os vídeos que elas contêm.
  • Estatísticas públicas dos vídeos do canal, como número de visualizações.
  • Comentários publicados pelo próprio canal nos próprios vídeos.

O aplicativo não coleta dados de espectadores, inscritos, visitantes ou de qualquer outra conta. Não coleta nome, e-mail, localização, contatos ou dados de pagamento de ninguém. Esta página e a página inicial não usam cookies, formulários nem ferramentas de rastreamento.

3. Como os dados são usados

Os dados são usados só para as tarefas de publicação do próprio canal: enviar e agendar vídeos; preencher e corrigir título, descrição e tags; definir miniaturas; enviar legendas; criar playlists e colocar vídeos nelas; publicar, em nome do canal, um comentário nos próprios vídeos; conferir o status e as visualizações dos vídeos; e remover um vídeo do canal, quando o dono decide tirá-lo do ar.

Os dados não são usados para publicidade, para criar perfis de pessoas nem para treinar modelos de inteligência artificial.

4. Com quem os dados são compartilhados

Os vídeos e as informações de cada vídeo são enviados ao YouTube, que é o destino da publicação. Fora isso, nenhum dado é vendido, alugado, compartilhado ou transferido a terceiros.

5. Como os dados são guardados e protegidos

A autorização do Google (token de acesso) fica guardada apenas no computador do dono do canal, numa pasta separada do código do aplicativo e fora de qualquer repositório público. Ela não é enviada a servidores de terceiros. Os dados dos vídeos ficam no próprio YouTube.

6. Por quanto tempo os dados ficam guardados e como apagá-los

O token de acesso fica guardado até que o dono do canal revogue a autorização ou apague o arquivo do token no computador. A autorização pode ser revogada a qualquer momento na página de permissões da Conta do Google. Depois de revogada, o aplicativo perde o acesso ao canal imediatamente.

7. Uso Limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Termos do YouTube e do Google

Ao usar este aplicativo, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

9. Alterações nesta política

Se o uso de dados do aplicativo mudar, esta página será atualizada antes da mudança, com a nova data no topo.

10. Contato

Dúvidas sobre esta política podem ser enviadas ao e-mail de suporte exibido na tela de permissão do Google ou pelo canal no YouTube.
