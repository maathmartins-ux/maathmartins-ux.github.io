# Choque Sinaptico — site do aplicativo

Página inicial e Política de Privacidade do aplicativo **Choque Sinaptico**, exigidas pelo Google para a tela de permissão OAuth.

- Publicado pelo GitHub Pages a partir da pasta `docs/`: https://maathmartins-ux.github.io/
- Site estático: sem JavaScript, sem formulário, sem cookies, com Content-Security-Policy restritiva.
- `verificar_site.py` barra, antes de cada commit, qualquer dado pessoal, segredo ou arquivo fora do previsto (repositório público).
